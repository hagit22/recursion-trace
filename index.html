חישוב עצרת ברקורסיה

public static int Factorial(int num) { if (num == 1) { return 1; } int result = Factorial(num - 1) * num; return result; }

איך מחשבים עצרת?

Factorial(6) = 6 · 5 · 4 · 3 · 2 · 1 = 720

הפעולה מקבלת מספר שלם חיובי num, ומחזירה את מכפלת כל המספרים מ-num ועד 1.

מה הפעולה עושה? DrawDown

הפעולה מדפיסה משולש הפוך: בשורה הראשונה number תווים, ובכל שורה תו אחד פחות.

  • number – מספר התווים בשורה הראשונה
  • tav – התו שמודפס

הפעולה DrawDown

private static void DrawDown(int number, char tav) { for (int i = 0; i < number; i++) { Console.Write(tav); } Console.WriteLine(); if (number > 1) { DrawDown(number - 1, tav); } }

מה הפעולה עושה? DrawUp

הפעולה מדפיסה משולש: בשורה הראשונה תו אחד, ובכל שורה תו אחד יותר, עד number תווים.

  • number – מספר התווים בשורה האחרונה
  • tav – התו שמודפס

הפעולה DrawUp

private static void DrawUp(int number, char tav) { if (number > 1) { DrawUp(number - 1, tav); } for (int i = 0; i < number; i++) { Console.Write(tav); } Console.WriteLine(); }

מעקב עבור DrawUp(3, '*')

מה הפעולה עושה? DrawPyramid

הפעולה מדפיסה פירמידה של rows שורות. בכל שורה מספר אי-זוגי של תווים, ולפניהם רווחים.

  • rows – מספר השורות
  • tav – התו שמודפס
  • indent – כמה רווחים לפני השורה התחתונה
בכל זימון: rows קטן ב-1 בכל זימון: indent גדל ב-1
פלט (· = רווח)
מי הדפיס?
····*
← DrawPyramid(1, '*', 4)
···***
← DrawPyramid(2, '*', 3)
··*****
← DrawPyramid(3, '*', 2)
·*******
← DrawPyramid(4, '*', 1)
*********
← DrawPyramid(5, '*', 0)

הפעולה DrawPyramid

private static void DrawPyramid(int rows, char tav, int indent) { if (rows > 1) DrawPyramid(rows - 1, tav, indent + 1); for (int i = 0; i < indent; i++) Console.Write(' '); for (int i = 0; i < 2 * rows - 1; i++) Console.Write(tav); Console.WriteLine(); }

מעקב עבור DrawPyramid(3, '*', 0)
